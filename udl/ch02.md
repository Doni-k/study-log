# Ch.2 — Supervised Learning

## Summary
A supervised learning model is simply a mathematical function, $ f[x, \phi] $, whose arguments consists of input value and parameter. Loss function, $ L[\phi] $, is used to measure the degree of how badly the model infers within given dataset. Regarding linear regression, calculating the optimal parameter is done easily by directly using derivative with respect to the two parameters (y-intercept, slope). 



## Key Concepts

- **Model:** a mapping from inputs to outputs, which is mathematical function
- **Loss:** a measured value indicating how poorly a model infers in certain dataset
- **Training:** to find parameter that minimizes loss
- **Overfitting:** a state of a model relying on the peculiarities of the given dataset and statistically atypical data and therefore showing low performance in other tests
- **Underfitting:** when a model is not expressive enough to capture the true relationship

## Derivations



### Least squares for 1D linear regression
$$
L[\phi] = \sum_{i=1}^{I} \left( \phi_0 + \phi_1 x_i - y_i \right)^2
$$

### 2.3 - Discriminative vs. generative linear regression

Data: $(2,1), (4,4), (-1,2)$

$$
\bar{x} = \frac{5}{3}, \quad \bar{y} = \frac{7}{3}, \quad
S_{xx} = \sum_{i}(x_i-\bar{x})^2 = \frac{38}{3}, \quad
S_{yy} = \sum_{i}(y_i-\bar{y})^2 = \frac{14}{3}, \quad
S_{xy} = \sum_{i}(x_i-\bar{x})(y_i-\bar{y}) = \frac{13}{3}
$$

**Discriminative** $y = \phi_0 + \phi_1 x$ (minimizes error along $y$):

$$
\begin{aligned}
\phi_1 &= \frac{S_{xy}}{S_{xx}} = \frac{13}{38} \approx 0.342 \\
\phi_0 &= \bar{y} - \phi_1 \bar{x} = \frac{67}{38} \approx 1.763 \\
y &\approx 0.342x + 1.763
\end{aligned}
$$

**Generative** $x = \phi_0' + \phi_1' y$ (minimizes error along $x$):

$$
\begin{aligned}
\phi_1' &= \frac{S_{xy}}{S_{yy}} = \frac{13}{14} \approx 0.929 \\
\phi_0' &= \bar{x} - \phi_1' \bar{y} = -\frac{1}{2} \\
\Rightarrow y &= \frac{14}{13}x + \frac{7}{13} \approx 1.077x + 0.538
\end{aligned}
$$

**Comparison.** Both lines pass through $(\bar{x}, \bar{y})$, but their slopes differ:

$$
\frac{\text{discriminative slope}}{\text{generative slope}}
= \frac{S_{xy}/S_{xx}}{S_{yy}/S_{xy}}
= \frac{S_{xy}^2}{S_{xx}S_{yy}} = r^2 \approx 0.318
$$

The two models give the same predictions only if $r^2 = 1$, i.e., all points lie exactly on a line.
