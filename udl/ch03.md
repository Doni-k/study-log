# Ch.3 — Shallow Neural Networks

## Summary
Shallow Neural Networks is neural network with only one hidden layer. Parameters consists of weights and biases. After linear combination of inputs and weights and added by bias, that value goes through activation function (ReLU in this book). ReLU function creates multiple linear region its number at most the number of hidden unit. According to Universal approximation Theorem, with sufficient number of hidden unit we can always approximate our given inputs to outputs with desired accuracy. This holds even in multivariate cases.

## Key Concepts
- **Shallow network:** Neural network with only one hidden layer
- **Hidden unit:** the number of neurons of the hidden layer
- **Activation function (ReLU):** x if x > 0, otherwise 0
- **Activation pattern:** the tipping points where each value is zero are the boundaries of other activation patterns
- **Linear region:** using ReLU as an activation function with $n$ hidden units, the number of linear regions is at most $n$
- **Universal approximation theorem:** any continuous function on compact subset of $\mathbb{R}^{D_i}$ to arbitrary precision

## Derivations
### 1. ReLU shallow network is piecewise linear
$$
y = \phi_0 + \sum_{d=1}^{D} \phi_d \, a\left[\theta_{d0} + \theta_{d1} x\right]
$$

### 2. Number of linear regions (1D input)
Since every parameter for ReLU function is linear and continuous, output of ReLU is also continuous piesewise linear.
### 3. Number of parameters
$$
D(D_i + 1) + D_o(D + 1)
$$

### 4. Multivariate inputs and outputs
$$
\begin{aligned}
h_d &= a[\theta_{d0} + \sum_{i=1}^{D_i}{\theta_{di}x_i}] \\
y_j &= \theta_{j0} + \sum_{d=1}^D{\theta_{jd}h_d}
\end{aligned}
$$
